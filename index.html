Role-Based Access Control

Secure access tailored to user responsibilities

Super Admin

Full Control
  • Full system access and control
  • Manage all users, roles, and permissions
  • System settings and configuration
  • Generate all reports and analytics
  • Backup and restore system data

Admin

Management
  • Manage assets, products, and stock
  • Handle suppliers and categories
  • Process sales and manage inventory
  • View and generate reports
  • Manage service logs

Staff/User

Limited Access
  • View and add sales entries
  • Update stock levels
  • Add service/maintenance logs
  • View limited reports
  • No access to user management
